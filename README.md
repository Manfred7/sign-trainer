# sign-trainer

Тренажёр для запоминания знаков «Книги перемен» (И-цзин): восьми триграмм ба-гуа и 64 гексаграмм. Он связывает три представления каждого знака: **изображение** из линий, **название** (Цянь, Ли, Кань…) и **перевод** (Небо, Огонь, Вода…).

Открыть: https://manfred7.github.io/sign-trainer/

## Что изучаем

- **Триграмма** — знак из трёх линий, **гексаграмма** — из шести. Сплошная линия — ян, прерывистая — инь.
- Линии читаются **снизу вверх**: первая линия — нижняя.
- Гексаграмма состоит из двух триграмм, нижней и верхней. В приложении состав записывается как «Вода над Огнём» (63 Цзи цзи). На нём держится всё изучение гексаграмм: знак читается как пара уже знакомых триграмм, а не как отдельная картинка.
- **Названия** даны в кириллице по системе Палладия, у гексаграмм к названию добавлен иероглиф. Он нужен, потому что некоторые названия совпадают: 10 Люй 履 и 56 Люй 旅, 27 И 頤 и 42 И 益 и другие.
- **Переводы гексаграмм** — по книге Б. Виногродского. Если у знака несколько вариантов перевода, они показываются через слэш, как у триграмм: «Водоём / Озеро».
- **Нумерация** — традиционный порядок Вэнь-вана, 1–64.

## Колоды

Знаки разбиты на колоды. Каждая следующая открывается, когда предыдущая освоена на **80%**:

| Колода | Что входит |
|---|---|
| Триграммы | 8 знаков ба-гуа |
| Удвоенные гексаграммы | 1, 2, 29, 30, 51, 52, 57, 58 — триграмма над самой собой. С них проще начинать гексаграммы. |
| Гексаграммы 1–8 … 57–64 | восемь колод по восемь знаков, по порядку номеров |
| Все гексаграммы | все 64 знака вперемешку |

Порог действует в режимах «Тренировка» и «Сборка». Ссылка «Открыть все» над списком колод снимает ограничение. Открытая колода больше не закрывается, даже если освоение потом упадёт. Остальные режимы порога не требуют (подробности ниже).

## Режимы

Режим выбирается на стартовом экране. Там же выбираются колода и длина сессии: 10, 20 или 40 карточек.

### Тренировка

Основной режим. На карточке показано одно представление знака, под ней 4 варианта ответа.

- **Направления вопросов** выбираются галочками. Их шесть, это все пары из трёх представлений:
  - Изображение → Перевод и Перевод → Изображение;
  - Изображение → Название и Название → Изображение;
  - Название → Перевод и Перевод → Название.

  По умолчанию включены первые два, это самые простые. Если выбрано несколько направлений, они чередуются.
- **Верный ответ** подсвечивается зелёным, на карточке раскрывается знак целиком: изображение, номер, название, иероглиф, перевод, а у гексаграмм и состав. Через секунду идёт следующая карточка.
- **Неверный ответ:** выбранный вариант красный, правильный зелёный, карточка раскрыта. Следующая карточка появляется по кнопке «Дальше», чтобы было время запомнить.
- **Неверные варианты усложняются** по мере того, как пара «знак × направление» выучивается:
  - уровень 0–1: случайные знаки из колоды;
  - уровень 2–3: знаки с общей триграммой (у триграмм — отличающиеся одной линией);
  - уровень 4–5: знаки, отличающиеся одной линией, тот же знак вверх ногами или с переставленными триграммами (11 ↔ 12, 63 ↔ 64). Такие варианты могут браться и из других колод.

  Двух вариантов с одинаковой надписью на кнопках не бывает.
- **Клавиши:** `1`–`4` — ответ, `Enter` или пробел — дальше.

### Знакомство

Листание карточек колоды без проверки. Удобно для первого знакомства перед тренировкой.

- На карточке всё сразу: изображение, номер, название, иероглиф, перевод. У гексаграммы справа от каждой половины подписана её триграмма («сверху: Кань 坎, Вода», «снизу: Ли 離, Огонь»), внизу строка состава «Вода над Огнём».
- Открыта любая колода, даже та, что ещё закрыта для тренировки.
- **Управление:** кнопки «Назад / Дальше», свайп влево и вправо, стрелки `←` `→`. `Esc` возвращает в меню.
- Прогресс в этом режиме не записывается.

### Состав

Тренирует чтение гексаграммы по половинам: по изображению нужно определить, из каких триграмм она сложена.

- Показывается гексаграмма с подсвеченной нижней половиной. Нужно выбрать её триграмму из восьми кнопок, затем то же для верхней.
- На кнопках только слова: перевод и название («Огонь / Ли»), без рисунков. Иначе задача свелась бы к сравнению картинок, а не к узнаванию.
- После каждого шага появляется подсказка: «Снизу: Огонь ✓» или «Снизу: Небо ✗ — верно Огонь». В конце раскрывается полная карточка с подписями триграмм.
- Ответ засчитывается, только если верны обе половины.
- Доступен для всех гексаграммных колод сразу: названия знать не нужно, достаточно триграмм. Для колоды триграмм режим недоступен.
- **Клавиши:** `1`–`8` — триграммы в порядке кнопок, `Enter` — дальше.

### Сборка

Обратная задача: по номеру, названию и переводу собрать сам знак. Способ ввода выбирается на стартовом экране.

- **Из триграмм:** выбрать нижнюю и верхнюю триграммы из восьми, как в «Составе». Подходит, чтобы связать название со составом.
- **По линиям:** конструктор из шести линий (у триграмм из трёх). Сначала все линии сплошные, тап по линии переключает её между сплошной и прерывистой. Линии пронумерованы снизу вверх, между триграммами оставлен зазор. После «Проверить» верные линии становятся зелёными, ошибочные красными, а на карточке показывается правильный знак. Это самая строгая проверка памяти на изображение.
- Триграммы собираются только по линиям.
- Колоды открываются так же, как в тренировке. У двух способов ввода отдельный прогресс.
- **Клавиши** в режиме «По линиям»: `1`–`6` переключают линию, `Enter` — проверить или дальше.

### Таблица

Все 64 гексаграммы в таблице 8 × 8: **строки — нижняя триграмма, столбцы — верхняя**. В заголовках строк и столбцов нарисованы триграммы с подписями.

- **Справочник:** в каждой клетке номер и рисунок знака. Тап по клетке открывает под таблицей карточку знака с составом. Прогресс не записывается.
- **Найди клетку:** показываются название, иероглиф и перевод (без номера), клетки пустые. Нужно тапнуть место знака в таблице, опираясь только на триграммы в заголовках. После ответа верная клетка подсвечивается зелёным, ошибочная — красным. У этой игры свой прогресс.

## Как считается прогресс

- **Уровни.** У каждой пары «знак × направление» есть уровень от 0 до 5 (система Лейтнера). Верный ответ повышает уровень на 1, ошибка сбрасывает в 0. «Состав», обе «Сборки» и «Найди клетку» считаются отдельными направлениями.
- **Выбор карточек.** Слабые пары выпадают чаще: у новой пары вес 6, у выученной до конца — 1. Один знак не выпадает два раза подряд. Пока в сессии есть знаки колоды, которых ещё не было, выбор идёт из них, поэтому каждый знак выпадает хотя бы раз.
- **Освоение.** Пара считается освоенной с уровня 3, то есть после трёх верных ответов подряд. Процент освоения колоды — это доля освоенных пар:
  - в тренировке — по выбранным направлениям;
  - в остальных режимах — по направлению самого режима.
- **Общий прогресс по знаку.** Прогресс хранится по знаку, а не по колоде. Например, 1 Цянь и 2 Кунь входят и в «Удвоенные», и в «1–8», поэтому вторая колода может открыться уже с ненулевым процентом.
- **Итоги сессии:**
  - процент верных ответов;
  - изменение освоения колоды («40% → 55%»);
  - сообщение, если открылась новая колода;
  - список знаков с ошибками.

  Кнопка «Повторить ошибки» запускает короткую сессию только по этим знакам.
- **Хранение.** Прогресс и настройки хранятся в браузере на устройстве (`localStorage`). Кнопка «Сбросить прогресс» внизу стартового экрана стирает прогресс и закрывает открытые колоды.

## Установка на телефон

Откройте https://manfred7.github.io/sign-trainer/ и установите как приложение:

- **Android (Chrome):** кнопка «Установить приложение» на стартовом экране или меню ⋮ → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает без интернета. Новые версии подтягиваются сами при следующем запуске с сетью. У установленного приложения и у сайта в браузере прогресс может быть раздельным.

## Запуск

```bash
npm install
npm run dev      # разработка, без service worker
npm run build && npm run preview   # собранная версия с офлайн-режимом: http://127.0.0.1:4173/sign-trainer/
npm run icons    # пересобрать иконки из public/pwa-icon.svg
```

## Стек

Vite, React, TypeScript, vite-plugin-pwa. Бэкенда нет. Сайт публикуется на GitHub Pages при каждом push в `main`.
