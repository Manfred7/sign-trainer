# sign-trainer

Тренажёр для запоминания восьми триграмм ба-гуа: связь между изображением, названием (Цянь, Ли, Кань…) и значением (Небо, Огонь, Вода…). Дальше — 64 гексаграммы.

## Как устроено

- Карточка с вопросом (изображение, название или перевод) и 4 варианта ответа.
- 6 направлений вопросов, выбираются на стартовом экране.
- После сессии — итоги и повтор ошибок.
- Клавиши `1`–`4` выбирают ответ, `Enter` — дальше.

## Установка на телефон

Откройте https://manfred7.github.io/sign-trainer/ и установите как приложение:

- **Android (Chrome):** кнопка «Установить приложение» на стартовом экране или меню ⋮ → «Установить приложение».
- **iPhone (Safari):** «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает без интернета. Новые версии подтягиваются сами при следующем запуске с сетью.

## Запуск

```bash
npm install
npm run dev      # разработка, без service worker
npm run build && npm run preview   # собранная версия с офлайн-режимом: http://127.0.0.1:4173/sign-trainer/
npm run icons    # пересобрать иконки из public/pwa-icon.svg
```

## Стек

Vite, React, TypeScript. Без бэкенда: настройки хранятся в `localStorage`.
